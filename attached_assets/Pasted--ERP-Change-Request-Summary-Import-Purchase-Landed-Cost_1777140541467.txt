# ERP Change Request Summary – Import Purchase / Landed Cost Module

## Objective

Enhance the existing ERP system to properly handle **import purchases from China**, calculate **accurate landed cost**, allocate shipment expenses across multiple products, and support **client-wise profitability**.

---

# Business Scenario

We import multiple products from China under one Purchase Order.
After shipment arrives, additional charges are paid to multiple vendors such as:

* Ocean Freight
* Customs Duty
* Clearing Agent Charges
* Port Charges
* Local Transport
* Insurance
* EX Works Pickup Charges

These imported products are then distributed/sold to multiple clients in India.

Need ERP to:

* Calculate true landed cost per product
* Split freight & charges correctly
* Update inventory cost
* Track shipment/job profitability
* Support client-wise margin analysis

---

* Gross Weight

## Formula

CBM = Length × Width × Height (meters)

Total CBM = Qty × Unit CBM

---

# Landed Cost Formula

For each item:

1. EXW Cost
2. Insurance Share
3. Freight Share (CBM based)
4. Assessable Value
5. INR Conversion
6. Customs Duty
7. Social Welfare Surcharge
8. Local Charges Share
9. Final Landed Cost

## Final Landed Cost

```text
Base Cost + Freight + Duty + SWS + Other Charges
```

## Per Unit Cost

```text
Final Landed Cost / Qty
```

# Important Notes for Developers

1. Build Shipment-Centric ERP, not only voucher-centric.

4. Maintain audit log for revised landed costs.
5. Multi-currency support mandatory.
